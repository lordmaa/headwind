Installing it
  1. Open this page on the phone and tap Download APK. If Android asks, allow your browser to install unknown apps (Settings → Apps → Special app access).
  2. Open the downloaded file and tap Install. If Play Protect warns about an unrecognised app, tap More details → Install anyway.
  3. Open Headwind. On this site go to Phones → Create token and scan the QR code from the app (or paste the link).
  4. Recording needs Location ("While using the app" is enough) and Notifications, so the recording notification shows. Recording continues with the screen off.

Updates: install the newer APK over the old one — it keeps your pairing because every build is signed with the same key.
