Home Assistant — MQTT

Publishes sensors to Home Assistant via MQTT Discovery — total rides, distance, elevation, calories, time, Everests, laps of Earth, and last ride details.

Garmin Connect

Pulls resting HR, HRV, sleep score, and body battery from Garmin Connect for richer AI coaching context.

Calorie burn adjustment

Burn figures are estimates and tend to read high. This takes a percentage off every burn estimate as it is pulled in (Garmin and FIT rides, phone recordings, walks and runs, Garmin daily totals). Everything downstream — dashboards, Home Assistant, the API and the Android app — then carries the corrected number. Food calories and figures you type in yourself are never changed, and the original number is always kept so this can be undone.

%

0 turns it off. "Apply to history" re-works your own stored rides, walks/runs and Garmin totals from their original numbers (rides received from friends are left alone). Run it again with a different percentage at any time.

Setup Guide
Home Assistant / MQTT

Enter broker details above. Sensors publish every 20 seconds and after every sync. Set the HA Device on each rider's profile for per-rider push notifications.

Garmin Connect

Enter credentials above and click Connect — if your account uses 2-step verification you'll be asked for the code right there, no command line needed. Recovery data syncs automatically every few hours after that.
